⚔ Enemy Editor

fractured

Edits stats/loadout for a real enemy.js class (not a mock), then hands off to enemy_test.html to actually spawn and fight it. Geometry/AI logic lives in enemy.js — this tool only tunes the numeric knobs every enemy already exposes as plain instance fields (health, attackCooldown, patrolRange), plus the ability loadout. It does not edit enemy.js itself — "Save JSON" gives you a paste-ready block for that.

Stats

Speed currently only affects enemy types that use the base Enemy class's own movement (patrol + chase) — a few types fully override movement with their own hardcoded speed and won't respond to this yet.
