👑 Boss Phase & Attack-Weight Editor

Edits phase data for the Sovereign (BOSS_PHASE_CONFIG, game/boss.js) and for every ComposedEnemy-based miniboss's def.phases array (game/enemy.js). This is the same data pickAttack()/_applyPhase() read at runtime; nothing here touches attack behavior itself (windup/hitboxes/telegraphs still live in boss.js's start*() methods or game/enemy.js's ATTACK_BEHAVIORS). Bespoke-class minibosses (Colossus Core, etc. — not built on ComposedEnemy) have no phase data and don't appear in the target list below.
