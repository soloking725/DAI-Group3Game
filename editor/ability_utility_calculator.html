◆ Ability Utility Calculator

Rough, tunable "how strong is this level" score per ability. There's no single objective definition of "utility" — damage, crowd control, and mobility aren't the same currency — so every number below is editable: the raw per-level stats (sourced from game/ability.js / player.js / game_state.js (game.js was split into 6 files 2026-07-27), with a few judgment-call fields like Mobility/Utility flagged) and the weights that combine them into one score. Use it to spot outliers (a level that costs the same lore pips as every other ability's same level but adds far less), not as a final verdict. All 6 abilities cost the identical 2 / 3 / 4 lore pips for Lv1/2/3 (game_state.js's INVENTORY_UPGRADES), so the "value per pip" column is directly comparable across abilities.

Weights

score = (damage×wD + ccFrames/10×wC + mobility×wM) / (1 + cooldownFrames/60 + pipCost×wP)
