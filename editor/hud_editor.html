HUD Layout

Drag elements on the mock screen, or type exact values. Coordinates are anchored (top-left / top-center / bottom-…) so layouts survive any canvas size. Every element has a "tooltip" field — the game has no mouse, so it renders as a persistent caption rather than a hover popup.

Add a new element

Freeform elements have no built-in game logic — they're positioned labels/icons/pip-rows for decoration or callouts.

Save / export

"Save": the game reads this on next load (HUD_LAYOUT overrides in game_hud_menus.js). "Export": paste-ready values for game_hud_menus.js's HUD_LAYOUT if you want them permanent. "Load from pasted JSON": paste a previously-exported block (or bare JSON) into the box below first, then click — replaces the working layout. "Write to file": same result as Export, but done for you — only works when running node editor/save-server.js and loading this page through http://localhost:8787. Click twice to confirm. "Reset": clears the saved override AND restores defaults here — never touches the source file.
