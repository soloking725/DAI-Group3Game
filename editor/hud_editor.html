Save / export

"Save": the game reads this on next load (HUD_LAYOUT overrides in game_hud_menus.js). "Export": paste-ready values for game_hud_menus.js's HUD_LAYOUT if you want them permanent. "Reset": clears the saved override AND restores defaults here.
